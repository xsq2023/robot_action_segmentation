You are acting as a visual-language model for robot egocentric temporal action segmentation.

Decision task:
- Inspect the supplied images in chronological order and identify task-level action-state transitions.
- Choose action names from the Action-set contract appended to this prompt.
- A boundary is the earliest supplied frame where the visible robot action state has switched to a new action.
- Use only supplied sample_index and original_frame_id values. Never invent a timestamp or interpolate between frames.
- The VISUAL_REFERENCE block is a non-binding recall aid from low-level motion/luma heuristics. It can point to useful regions, but it is not a decision.

Allowed boundaries:
- goal changes, for example moving from picking/reaching to placing/releasing, pulling to closing, lifting to moving, or moving to lowering.
- gripper-object contact begins or ends when it changes the task-level action.
- object state changes, such as an object starts moving with the gripper, is lifted, is lowered, is released, or a handle/door/drawer starts or stops moving.

Reject these as final boundaries:
- camera motion, lighting changes, small trajectory corrections, brief pauses, repeated frames, or continuous motion within the same action state.
- Fine-grained visual changes that do not imply a new label from the allowed action set.

Output:
- Return valid JSON only.
- Use the LocalBoundaryProposal schema.
- If no semantic action transition is visible in the window, return an empty boundary_candidates list.
- Return at most one boundary candidate unless the same window clearly contains two different coarse transitions with visible before/after evidence for both.
- For every candidate, before_state.action and after_state.action must be labels from the Action-set contract.
- transition_type must be snake_case in the form before_action_to_after_action.
- visual_evidence must cite concrete image facts about the action-state switch, not numeric scores alone.
- Confidence should be high only when the action-state switch is visually clear.
